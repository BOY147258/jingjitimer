## 🔧 故障排查

### 问题 1：手机显示「无法连接到服务器」

**原因：** 防火墙阻止了连接

**解决方案：**

#### Windows 防火墙临时关闭（测试用）
1. 按 Win + R
2. 输入：`firewall.cpl`
3. 点击「启用或关闭 Windows 防火墙」
4. 勾选「关闭防火墙」
5. 点击「确定」
6. 再用手机访问试试

#### 或者：添加防火墙规则（推荐）
运行以下命令（管理员权限）：
```
netsh advfirewall firewall add rule name="竞迹计时-8080" dir=in action=allow protocol=TCP localport=8080
```

---

### 问题 2：手机和电脑不在同一 WiFi

**解决方案：**
1. 让手机连接到和电脑相同的 WiFi
2. 或者：部署到云端（不需要同一WiFi）

---

### 问题 3：IP 地址变了

**症状：** 之前能用，现在突然不能用了

**原因：** 电脑重启后 IP 地址可能变化

**解决方案：**
每次使用前检查电脑 IP：
```
ipconfig | findstr "IPv4"
```

找到 `192.168.x.x` 格式的地址（不是 172.19.0.1）
